# 从这里改前端

打开 `src/components`，文件名就是界面名称。

- `首页.jsx / 首页.css`：官网首页。
- `训练中心.jsx / 训练中心.css`：训练中心布局和案例列表。
- `当前视频卡片.jsx / 当前视频卡片.css`：视频卡片、指标和蓝色“继续”按钮。
- `侧边导航.jsx / 侧边导航.css`：左侧导航。
- `训练分析.jsx / 训练分析.css`：视频分析、标定和结果。
- `功能页面.jsx / 功能页面.css`：姿态、回放、报告、模型页面；代码内有中文分段。
- `视频片段弹窗`、`重命名弹窗`：对应弹窗。

`.jsx` 改文字和交互，`.css` 改字体、方框和间距。样式里用中文注释标了区域，块之间有空行。

蓝色“继续”按钮：打开 `当前视频卡片.css`，搜索“继续”。

全局字体和颜色在 `src/styles/base.css`；数据和页面切换在 `应用状态.jsx`；公共函数在 `src/shared.js`。

在 frontend 目录执行 `npm run dev` 可边改边看；打包运行版用 `npm run build`。
