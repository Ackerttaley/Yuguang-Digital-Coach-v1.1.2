# 羽光智教 v1.1.2

羽光智教是一款面向羽毛球训练的视频分析工具，可在本地导入视频，查看球员跑位、球场热力图和训练报告。

## v1.1.2 更新

1. 优化前端显示，调整训练分析、报告和回放页面。
2. 优化球场标定，支持自动识别白线、拖动角点以及调整画面边缘外的角点，方便对齐场地。
3. 优化 2.5D 回放：视频与球场轨迹按时间同步，并显示球场线框和脚部检测位置，方便核对跑位。
4. 引入 **RTMPose-M** 人体姿态模型，与 MediaPipe BlazePose 可在界面中切换；跑位分析使用选中的模型。

## Windows 运行

1. 下载或克隆本仓库，进入项目目录。
2. 双击 `start.cmd` 启动平台。
3. 浏览器访问 `http://127.0.0.1:8012`，导入 MP4 视频并选择分析区间。

仓库包含 Windows 运行时及前端构建文件；修改前端源码后，可在 `frontend` 目录执行 `npm install` 和 `npm run build`。更多说明见 [howtoinstall.md](howtoinstall.md)。

> `stop.cmd` 会停止服务并清空本项目 `videos` 和 `data` 目录中的视频、分析结果和缓存。请在使用前确认这些数据不再需要。

## 主要目录

- `frontend/src`：页面和交互源码。
- `frontend/public`：姿态模型、球场识别和浏览器推理资源。
- `backend`：本地 API、视频管理和分析结果处理。
- `runtime`：Windows Python 运行环境及依赖。
- `scripts`：启动、停止与前端构建脚本。

视频和分析结果保存在本机，不包含在仓库中。球场白线识别和跑位映射受画面质量、遮挡及场地标定影响，使用时可通过视频中的线框和脚部位置进行核对。
